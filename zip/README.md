# 郵便番号からお住まいの場所を引き当てる一覧（zip/）

作成：2026-10-05。**お住まいの画面（home_city.html）と、GASの home_zip.js が読みます。**

## これは何か

郵便番号の上3桁ごとに1ファイル。中身は「下4桁 → お住まいの場所」の対応です。

```
zip/153.json  →  {"0051":["東京都","目黒区","上目黒",35.642823,139.694083,1], ...}
```

最後の数字は印です。**1＝町名まで分かっている／0＝市区町村までしか分からない。**

- ファイル数 **942**／郵便番号 **116,896件**／合計 **8.0MB**／1ファイル平均 **8.7KB**（最大 77.9KB）
- 画面は、打たれた郵便番号の上3桁のファイル1つだけを読みます（全部は読みません）

## 出どころ

| 中身 | 出どころ | 決まり |
|---|---|---|
| 郵便番号と住所の対応 | 日本郵便（2026-10-03版） | 自由に使えます |
| 町名ごとの場所（緯度・経度） | geolonia/japanese-addresses（全国27万7千件） | MIT |

## 作ったときに数えたこと

- 町名まで場所が出せた … **93.7%**
- 市区町村までしか出せなかった … 6.0%（いままでと同じ細かさ。悪くなりません）
- 1つも出せなかった … 388件（0.3%）← その郵便番号は受け付けません
- ビルの階ごとの郵便番号 3,437件は、住まいではないので **外してあります**
- 市区町村の代表の場所から、**中央値で3.4km** 動きます（高山市は中央値9.7km・いちばん遠い町で38.2km）

## 作り直し方

1. 郵便番号データ … `https://raw.githubusercontent.com/polm/posuto/master/raw/ken_all.utf8.csv` を `ken_all.csv` として保存
2. 町名ごとの場所 … `https://raw.githubusercontent.com/geolonia/japanese-addresses/master/data/latest.csv` を `geolonia.csv` として保存
3. つなぎ合わせて `zip_points.json` を作り、`python3 build.py <出す先のフォルダ>` を実行

★つなぎ合わせの決まり（「字」「大字」の有無をそろえる・漢数字を数字にそろえる・ビルの階ごとは外す）は
`build.py` の上にある作り方のメモと、docs の作業記録に書いてあります。

## 本番へ上げるとき（リリース番へ）

★**この zip/ フォルダをまるごと、home_city.html と同じ階層に置いてください。**
置かないと、郵便番号の道が動きません（「郵便番号がわからない方」の選び方だけが残ります）。

GAS側の置き場は CONFIG の `home_zip_base_url` で変えられます。行が無ければ
`https://saygo1971.github.io/jcj-liff/zip` を読みます（home_zip.js）。
